# Fonts

## m6x11 (required)

1. Download **m6x11.ttf** from [managore.itch.io/m6x11](https://managore.itch.io/m6x11) (Daniel Linssen).
2. Place it here: `public/fonts/m6x11.ttf`.
3. Credit the author in shipped builds (see `ATTRIBUTION.md`).

**Sizes (author recommendation):** use **16, 32, 48** px only for m6x11 — aligns with `PIXEL_SCALE` ×4 (64 px cell).

Optional **m6x11plus.ttf** for extended charset at **18, 36, 54** px.
